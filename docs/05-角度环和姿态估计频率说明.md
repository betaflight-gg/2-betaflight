# Betaflight 角度环和姿态估计频率说明

## 概述

本文档详细说明Betaflight中姿态估计、角度环和角速度环的运行频率关系。

## 频率详解

### 1. 姿态估计频率（TASK_ATTITUDE）

#### 默认频率：100Hz

姿态估计任务默认运行频率为 **100Hz**（每10ms执行一次）。

#### 动态频率调整

当进入角度模式（ANGLE_MODE）、地平线模式（HORIZON_MODE）、高度保持（ALT_HOLD_MODE）或位置保持（POS_HOLD_MODE）时，频率会动态提升：

```1091:1098:src/main/fc/core.c
    if (FLIGHT_MODE(ANGLE_MODE | ALT_HOLD_MODE | POS_HOLD_MODE | HORIZON_MODE)) {
        LED1_ON;
        // increase frequency of attitude task to reduce drift when in angle or horizon mode
        rescheduleTask(TASK_ATTITUDE, TASK_PERIOD_HZ(acc.sampleRateHz / (float)imuConfig()->imu_process_denom));
    } else {
        LED1_OFF;
        rescheduleTask(TASK_ATTITUDE, TASK_PERIOD_HZ(100));
    }
```

**计算公式：**
```
姿态估计频率 = acc.sampleRateHz / imu_process_denom
```

**典型值：**
- `acc.sampleRateHz` = 1000 Hz（加速度计采样率，默认值）
- `imu_process_denom` = 2（默认值，见 `src/main/flight/imu.c:127`）
- **角度模式下的姿态估计频率 = 1000 / 2 = 500 Hz**

**配置参数：**
- `imu_process_denom`：范围 1-4，默认值为 2
- 位置：`src/main/flight/imu.c:127`

### 2. 角速度环频率（PID任务）

**角速度环频率 = PID任务频率**

PID任务频率由陀螺仪采样频率和 `pid_process_denom` 决定：

```
角速度环频率 = 陀螺仪采样频率 / pid_process_denom
```

**典型配置：**
- 陀螺仪采样频率：通常为 8kHz 或 32kHz（取决于硬件）
- `pid_process_denom`：通常为 1（表示每个陀螺仪采样都执行PID）
- **角速度环频率 = 8000 / 1 = 8kHz** 或 **32000 / 1 = 32kHz**

**如果PID频率是3.2kHz：**
- 可能是 `pid_process_denom = 10`，陀螺仪采样频率 = 32kHz
- 或者 `pid_process_denom = 2.5`，陀螺仪采样频率 = 8kHz（不太可能，因为denom通常是整数）

**实际运行时：**
PID任务的实际频率在初始化时由 `gyro.targetLooptime` 决定：

```615:622:src/main/fc/tasks.c
    if (sensors(SENSOR_GYRO)) {
        rescheduleTask(TASK_GYRO, gyro.sampleLooptime);
        rescheduleTask(TASK_FILTER, gyro.targetLooptime);
        rescheduleTask(TASK_PID, gyro.targetLooptime);
        setTaskEnabled(TASK_GYRO, true);
        setTaskEnabled(TASK_FILTER, true);
        setTaskEnabled(TASK_PID, true);
        schedulerEnableGyro();
    }
```

### 3. 角度环频率

**重要：角度环在PID任务内部运行，因此频率与角速度环相同！**

角度环的代码在 `pidController()` 函数中：

```1276:1282:src/main/flight/pid.c
        pidRuntime.axisInAngleMode[axis] = false;
        if (axis < FD_YAW) {
            if (levelMode == LEVEL_MODE_RP || (levelMode == LEVEL_MODE_R && axis == FD_ROLL)) {
                pidRuntime.axisInAngleMode[axis] = true;
                currentPidSetpoint = pidLevel(axis, pidProfile, angleTrim, currentPidSetpoint, horizonLevelStrength);
            }
        }
```

**因此：**
- **角度环频率 = PID任务频率 = 角速度环频率**

如果PID频率是3.2kHz，那么角度环频率也是 **3.2kHz**。

## 频率关系总结

### 假设PID频率为3.2kHz的情况

| 组件 | 频率 | 说明 |
|------|------|------|
| **角速度环** | **3.2 kHz** | 在PID任务中运行，每次PID循环都执行 |
| **角度环** | **3.2 kHz** | 在PID任务中运行，每次PID循环都执行（仅在角度模式下） |
| **姿态估计（默认）** | **100 Hz** | 独立任务，非角度模式下 |
| **姿态估计（角度模式）** | **500 Hz** | 独立任务，角度模式下动态提升（假设acc.sampleRateHz=1000, imu_process_denom=2） |
| **加速度计采样** | **1000 Hz** | 独立任务TASK_ACCEL |

### 数据流和频率关系

```
时间轴（以3.2kHz PID为例，312.5μs周期）
────────────────────────────────────────────────────────────→

PID循环 #1 (0μs)
├─ 读取姿态数据（从attitude结构体，由姿态估计任务更新）
├─ 角度环计算（3.2kHz）- 如果启用角度模式
│  └─ 使用当前角度：attitude.raw[axis]（由姿态估计任务更新）
├─ 角速度环计算（3.2kHz）
└─ 电机输出更新

PID循环 #2 (312.5μs)
├─ 角度环计算（3.2kHz）
├─ 角速度环计算（3.2kHz）
└─ ...

── 独立时间线 ──

每 2ms (500Hz) - 角度模式下
└─ 姿态估计任务（TASK_ATTITUDE）
   ├─ 读取加速度计数据（已由TASK_ACCEL在1kHz更新）
   ├─ 读取陀螺仪数据（已由TASK_GYRO在8kHz更新）
   ├─ Mahony AHRS算法融合
   └─ 更新attitude结构体（roll, pitch, yaw）

每 10ms (100Hz) - 非角度模式下
└─ 姿态估计任务（TASK_ATTITUDE）
   └─ 同上

每 1ms (1000Hz)
└─ 加速度计任务（TASK_ACCEL）
   └─ 读取加速度计原始数据
```

## 关键点说明

### 1. 姿态估计是独立任务

- ✅ **姿态估计在独立任务中运行**（TASK_ATTITUDE）
- ✅ 默认频率：100Hz
- ✅ 角度模式下自动提升到 500Hz（典型配置）

### 2. 角度环和角速度环在同一任务

- ✅ **角度环和角速度环都在PID任务中运行**
- ✅ **频率相同**，都等于PID任务频率
- ✅ 如果PID是3.2kHz，那么角度环和角速度环都是3.2kHz

### 3. 数据同步

姿态估计任务更新 `attitude` 结构体，PID任务读取该结构体：

```596:596:src/main/flight/pid.c
    const float currentAngle = (attitude.raw[axis] - angleTrim->raw[axis]) / 10.0f; // stepped at 500hz with some 4ms flat spots
```

**注意：** 注释中提到"stepped at 500hz"，这是因为在角度模式下姿态估计运行在500Hz，所以角度数据每2ms更新一次。但PID任务在3.2kHz运行，所以每次PID循环读取的角度值可能是"旧的"（最多2ms延迟）。

### 4. 频率配置参数

| 参数 | 默认值 | 位置 | 说明 |
|------|--------|------|------|
| `imu_process_denom` | 2 | `src/main/flight/imu.c:127` | 控制角度模式下姿态估计频率 |
| `pid_process_denom` | 1 | 配置中 | 控制PID任务频率 |
| `acc.sampleRateHz` | 1000 | 加速度计初始化 | 加速度计采样率 |

## 实际运行示例

### 场景：PID频率 = 3.2kHz

**配置假设：**
- 陀螺仪采样：32kHz
- `pid_process_denom` = 10
- `acc.sampleRateHz` = 1000 Hz
- `imu_process_denom` = 2

**实际频率：**

1. **角速度环：** 3.2 kHz（每个PID循环执行）
2. **角度环：** 3.2 kHz（每个PID循环执行，仅在角度模式下）
3. **姿态估计（非角度模式）：** 100 Hz（每10ms执行一次）
4. **姿态估计（角度模式）：** 500 Hz（每2ms执行一次）
5. **加速度计采样：** 1000 Hz（每1ms执行一次）

**时序关系：**
- 每1ms：加速度计更新数据
- 每2ms（角度模式下）：姿态估计更新角度数据
- 每312.5μs（3.2kHz）：PID任务执行，包括角度环和角速度环

---

## 总结

1. ✅ **姿态估计是独立任务**，默认100Hz，角度模式下提升到500Hz（典型配置）
2. ✅ **角度环频率 = 角速度环频率 = PID任务频率**
3. ✅ 如果PID是3.2kHz，那么：
   - 角速度环：**3.2 kHz**
   - 角度环：**3.2 kHz**
   - 姿态估计（角度模式）：**500 Hz**（假设默认配置）
   - 姿态估计（非角度模式）：**100 Hz**

4. ⚠️ **数据延迟**：角度环在3.2kHz运行，但读取的角度数据由500Hz的姿态估计任务更新，因此存在最多2ms的延迟（在角度模式下）。
