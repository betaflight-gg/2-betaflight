# 姿态估计所需数据详解

## 概述

姿态估计（Attitude Estimation）使用Mahony AHRS算法融合多个传感器数据来估计飞行器的姿态（roll、pitch、yaw）。本文档详细说明姿态估计需要哪些原始数据，以及这些数据的来源。

---

## 必需数据（核心传感器）

### 1. 陀螺仪数据（Gyro Data）

**用途：** 提供角速度信息，用于积分计算姿态变化

**数据来源：**
```710:713:src/main/flight/imu.c
    float gyroAverage[XYZ_AXIS_COUNT];
    for (int axis = 0; axis < XYZ_AXIS_COUNT; ++axis) {
        gyroAverage[axis] = gyroGetFilteredDownsampled(axis);
    }
```

**数据流：**
```
陀螺仪硬件芯片
  ↓ (SPI/I2C读取)
TASK_GYRO (3.2kHz)
  ↓ gyroUpdate()
gyro.gyroADC[axis] (原始ADC值)
  ↓
TASK_FILTER (条件执行)
  ↓ taskFiltering()
  ├─ 下采样（downsampling）
  ├─ RPM滤波器（可选）
  ├─ 静态陷波滤波器
  └─ 低通滤波器
gyro.gyroADCf[axis] (滤波后)
  ↓
PT1滤波器（50Hz截止，用于IMU）
  ↓
gyroFilteredDownsampled[axis]
  ↓
gyroGetFilteredDownsampled(axis)
  ↓
姿态估计使用
```

**关键代码位置：**
- 读取：`src/main/sensors/gyro.c:550` - `gyroGetFilteredDownsampled()`
- 滤波：`src/main/sensors/gyro.c:541` - PT1滤波器应用
- 单位：度/秒（deg/s），在调用时转换为弧度/秒

**在姿态估计中的使用：**
```716:717:src/main/flight/imu.c
    imuMahonyAHRSupdate(dt,
                        DEGREES_TO_RADIANS(gyroAverage[X]), DEGREES_TO_RADIANS(gyroAverage[Y]), DEGREES_TO_RADIANS(gyroAverage[Z]),
```

---

### 2. 加速度计数据（Accelerometer Data）

**用途：** 提供重力方向信息，用于修正姿态估计的漂移

**数据来源：**
```715:718:src/main/flight/imu.c
    const bool useAcc = imuIsAccelerometerHealthy(); // all smoothed accADC values are within 10% of 1G
    imuMahonyAHRSupdate(dt,
                        DEGREES_TO_RADIANS(gyroAverage[X]), DEGREES_TO_RADIANS(gyroAverage[Y]), DEGREES_TO_RADIANS(gyroAverage[Z]),
                        useAcc, acc.accADC.x, acc.accADC.y, acc.accADC.z,
```

**数据流：**
```
加速度计硬件芯片（通常和陀螺仪在同一芯片上）
  ↓ (SPI/I2C读取)
TASK_ACCEL (1000Hz或更高)
  ↓ accUpdate()
acc.dev.ADCRaw[axis] (原始ADC值)
  ↓
alignAccelerometer() (传感器对齐)
  ↓
calibrateAccelerometer() (校准)
  ↓
applyAccelerationTrims() (应用Trim)
  ↓
postProcessAccelerometer() (后处理)
  ├─ PT2低通滤波（可选，acc_lpf_hz）
  └─ 计算jerk（加速度变化率）
  ↓
acc.accADC[axis] (最终值)
  ↓
姿态估计使用
```

**关键代码位置：**
- 读取：`src/main/sensors/acceleration.c:107` - `accUpdate()`
- 处理：`src/main/sensors/acceleration.c:44-122` - 对齐、校准、滤波
- 单位：ADC原始值，需要归一化

**健康检查：**
```322:326:src/main/flight/imu.c
static bool imuIsAccelerometerHealthy(void)
{
    // Accept accel readings only in range 0.9g - 1.1g
    return (0.9f < acc.accMagnitude) && (acc.accMagnitude < 1.1f);
}
```

**在姿态估计中的使用：**
- 如果 `useAcc = true`（加速度计数据健康），则用于修正姿态
- 如果 `useAcc = false`（飞行中加速度变化大），则不使用加速度计数据，仅依赖陀螺仪

### 4. GPS数据（GPS Data）- 可选

**用途：** 提供地面航向（Course Over Ground），用于修正yaw角度

**数据来源：**
```673:705:src/main/flight/imu.c

    float cogErr = 0;

        && sensors(SENSOR_GPS)
        && STATE(GPS_FIX) && gpsSol.numSat > GPS_MIN_SAT_COUNT) {
        // ... 计算cogErr ...

```

**数据流：**
```

  ↓ (UART/SPI读取)

  ↓ gpsUpdate()

gpsSol.groundSpeed (地面速度)
  ↓
imuCalcCourseErr() (计算航向误差)
  ↓
cogErr (航向误差，rad/s)
  ↓

```

**关键代码位置：**
- GPS更新：`src/main/io/gps.c` - `gpsUpdate()`
- 误差计算：`src/main/flight/imu.c:550` - `imuCalcCourseErr()`

**使用条件：**
- 仅在**没有磁力计**时使用（`!useMag`）
- 需要GPS定位（`GPS_FIX`）
- 需要足够的卫星数（`numSat > GPS_MIN_SAT_COUNT`）

## 时间数据

### 5. 时间间隔（Delta Time）

**用途：** 用于积分计算，将角速度转换为角度变化

**数据来源：**
```646:650:src/main/flight/imu.c
    static timeUs_t previousIMUUpdateTime = 0;
    const timeDelta_t deltaT = currentTimeUs - previousIMUUpdateTime;
    previousIMUUpdateTime = currentTimeUs;
#endif
    const float dt = deltaT * 1e-6f;
```

**计算方式：**
- `dt = (currentTimeUs - previousIMUUpdateTime) * 1e-6f`
- 单位：秒（s）

**在姿态估计中的使用：**
```271:273:src/main/flight/imu.c
    // Integrate rate of change of quaternion
    gx *= (0.5f * dt);
    gy *= (0.5f * dt);
    gz *= (0.5f * dt);
```

## 数据对比表

### PID控制器 vs 姿态估计

| 数据源 | PID控制器 | 姿态估计 | 说明 |
|--------|-----------|----------|------|
| **陀螺仪** | ✅ 必需 | ✅ 必需 | PID用原始滤波数据，姿态估计用下采样滤波数据 |
| **加速度计** | ❌ 不需要 | ✅ 必需 | 仅姿态估计需要 |
| **遥控器** | ✅ 必需 | ❌ 不需要 | 仅PID需要 |
| **磁力计** | ❌ 不需要 | ⚠️ 可选 | 仅姿态估计需要（yaw修正） |
| **GPS** | ❌ 不需要 | ⚠️ 可选 | 仅姿态估计需要（yaw修正） |

## 数据来源总结

### 必需数据

1. **陀螺仪数据**
   - 来源：`gyroGetFilteredDownsampled(axis)`
   - 任务：TASK_GYRO + TASK_FILTER
   - 频率：3.2kHz（采样）→ 下采样后用于姿态估计
   - 单位：度/秒 → 转换为弧度/秒

2. **加速度计数据**
   - 来源：`acc.accADC.x/y/z`
   - 任务：TASK_ACCEL
   - 频率：1000Hz或更高（取决于配置）
   - 单位：ADC原始值（归一化后使用）

3. **时间间隔**
   - 来源：`currentTimeUs - previousIMUUpdateTime`
   - 计算：在`imuCalculateEstimatedAttitude`中计算
   - 单位：秒（s）

### 可选数据

4. **磁力计数据**（可选）
   - 来源：`mag.magADC` → `imuCalcMagErr()`
   - 任务：TASK_COMPASS
   - 频率：低频率（如10Hz）
   - 用途：修正yaw角度

5. **GPS数据**（可选）
   - 来源：`gpsSol.groundCourse` → `imuCalcCourseErr()`
   - 任务：TASK_GPS
   - 频率：低频率（如5-10Hz）
   - 用途：修正yaw角度（仅在无磁力计时使用）

## 总结

### 姿态估计需要的数据：

1. ✅ **陀螺仪数据**（必需）- 来自TASK_GYRO/TASK_FILTER，经过滤波和下采样
2. ✅ **加速度计数据**（必需）- 来自TASK_ACCEL，经过对齐、校准、滤波
3. ✅ **时间间隔**（必需）- 在姿态估计任务中计算
4. ⚠️ **磁力计数据**（可选）- 来自TASK_COMPASS，用于yaw修正
5. ⚠️ **GPS数据**（可选）- 来自TASK_GPS，用于yaw修正（无磁力计时）

### 与PID控制器的对比：

- **PID控制器需要：** 陀螺仪数据 + 遥控器数据
- **姿态估计需要：** 陀螺仪数据 + 加速度计数据 + （可选）磁力计/GPS数据

姿态估计**不依赖遥控器数据**，它是基于传感器数据的自主姿态估计。
