# Betaflight 角度环移植步骤指南

## 概述

角度环（Angle Mode）是Betaflight中的自稳模式，它通过加速度计估计飞行器姿态角度，然后将角度误差转换为角速度设定点，输入到角速度环进行控制。

角度环的实现分为两个主要部分：
1. **角度估计**（IMU部分）：使用加速度计和陀螺仪数据估计飞行器姿态
2. **角度PID控制**（PID部分）：将角度误差转换为角速度设定点

## 第二部分：角度PID控制（PID部分）

### 2.1 角度环核心函数：`pidLevel`

**函数签名：**
```c
float pidLevel(int axis, const pidProfile_t *pidProfile, 
               const rollAndPitchTrims_t *angleTrim,
               float currentPidSetpoint, float horizonLevelStrength)
```

**功能说明：**
- 将角度误差转换为角速度设定点
- 只应用于ROLL和PITCH轴（不用于YAW）
- 输入：当前角速度设定点（来自遥控器）
- 输出：修正后的角速度设定点（输入到角速度环）

**关键步骤：**

1. **计算角度目标值**
   ```c
   float angleTarget = angleLimit * currentPidSetpoint * maxSetpointRateInv;
   angleTarget = constrainf(angleTarget, -angleLimit, angleLimit);
   ```

2. **计算当前角度**
   ```c
   const float currentAngle = (attitude.raw[axis] - angleTrim->raw[axis]) / 10.0f;
   ```

3. **计算角度误差和角速度设定点**
   ```c
   const float errorAngle = angleTarget - currentAngle;
   float angleRate = errorAngle * pidRuntime.angleGain + angleFeedforward;
   ```

4. **应用前馈（Feedforward）**
   ```c
   angleFeedforward = pt3FilterApply(&pidRuntime.angleFeedforwardPt3[axis], angleFeedforward);
   ```

5. **平滑输出**
   ```c
   angleRate = pt3FilterApply(&pidRuntime.attitudeFilter[axis], angleRate);
   ```

**参考代码位置：**
- `src/main/flight/pid.c:552` - `pidLevel` 函数完整实现

```c
        }
```

### 2.3 角度环参数初始化

**在 `pidInitFilters` 中初始化角度相关滤波器：**

```c
#ifdef USE_ACC
    // 姿态滤波器（50Hz截止频率）
    const float k = pt3FilterGain(ATTITUDE_CUTOFF_HZ, pidRuntime.dT);
    
    // 角度前馈滤波器
    const float angleCutoffHz = 1000.0f / (2.0f * M_PIf * 
                           pidProfile->angle_feedforward_smoothing_ms);
    const float k2 = pt3FilterGain(angleCutoffHz, pidRuntime.dT);
    
    // 初始化ROLL和PITCH的滤波器
    for (int axis = 0; axis < 2; axis++) {
        pt3FilterInit(&pidRuntime.attitudeFilter[axis], k);
        pt3FilterInit(&pidRuntime.angleFeedforwardPt3[axis], k2);
    }
    
    pidRuntime.angleYawSetpoint = 0.0f;
#endif
```

**在 `pidInitConfig` 中初始化角度相关参数：**

```c

// 角度前馈增益（从PID_LEVEL的F参数计算）
pidRuntime.angleFeedforwardGain = pidProfile->pid[PID_LEVEL].F / 100.0f;

// 地平线模式相关参数
```

## 第三部分：配置和模式管理

### 3.1 飞行模式定义

**需要支持的模式：**

1. **ANGLE_MODE** - 纯角度模式
   - 完全自稳，ROLL和PITCH都使用角度环

2. **HORIZON_MODE** - 地平线模式
   - 混合模式：小角度时自稳，大角度时手动
   - 使用 `calcHorizonLevelStrength` 计算混合强度

3. **ACRO_MODE** - 手动模式
   - 不使用角度环，直接使用角速度环

**模式判断逻辑：**

```c
levelMode_e levelMode;
if (FLIGHT_MODE(ANGLE_MODE | HORIZON_MODE | GPS_RESCUE_MODE)) {
    if (pidRuntime.levelRaceMode && !isExternalAngleModeRequest) {
        levelMode = LEVEL_MODE_R;  // 仅ROLL使用角度环
    } else {
        levelMode = LEVEL_MODE_RP; // ROLL和PITCH都使用角度环
    }
} else {
    levelMode = LEVEL_MODE_OFF;    // 不使用角度环
}
```

**参考代码位置：**
- `src/main/flight/pid.c:1154` - 模式判断逻辑

### 3.2 PID配置文件参数

**角度环相关参数（在 `pidProfile_t` 中）：**

```c
pidf_t pid[PID_ITEM_COUNT];  // PID参数数组
// PID_LEVEL 索引用于角度环：
//   P: 角度环增益（转换为 angleGain = P / 10.0）
//   I: 地平线模式增益（转换为 horizonGain = I / 100.0）
//   D: 地平线模式摇杆限制（转换为 horizonLimitSticks = D / 100.0）
```

## 第五部分：测试和调试

### 5.1 调试输出

**可用的调试通道：**

1. **DEBUG_ANGLE_MODE** - 角度模式调试
   - [0]: 目标角度（度 × 10）
   - [1]: 未平滑的角度误差修正（度 × 10）
   - [2]: 前馈量（度 × 10）
   - [3]: 当前角度（度 × 10）

2. **DEBUG_CURRENT_ANGLE** - 当前角度
   - [axis]: 当前角度（度 × 10）

3. **DEBUG_ATTITUDE** - 姿态数据
   - [0]: Roll角度（0.1度）
   - [1]: Pitch角度（0.1度）

**参考代码位置：**
- `src/main/flight/pid.c:621` - 角度模式调试输出
- `src/main/flight/imu.c:774` - 姿态调试输出

### 5.2 验证步骤

1. **加速度计数据验证**
   - 检查 `acc.accADC` 是否有有效数据
   - 检查 `acc.accMagnitude` 是否接近1.0（1G）

2. **姿态估计验证**
   - 检查 `attitude.values.roll` 和 `attitude.values.pitch` 是否合理
   - 静止时应该接近0度

3. **角度环输出验证**
   - 在角度模式下，检查 `pidLevel` 的输出
   - 验证角度误差是否正确转换为角速度设定点

4. **模式切换验证**
   - 测试ANGLE_MODE、HORIZON_MODE、ACRO_MODE之间的切换
   - 验证 `pidRuntime.axisInAngleMode` 标志是否正确设置

## 常见问题

### Q1: 角度环不工作，飞行器无法自稳
**检查：**
1. `USE_ACC` 宏是否定义
2. 加速度计是否初始化成功（`acc.isAccelUpdatedAtLeastOnce`）
3. `imuUpdateAttitude` 是否被定期调用
4. `pidRuntime.axisInAngleMode[axis]` 是否正确设置为true

### Q2: 角度估计不准确
**检查：**
1. 加速度计校准是否正确
2. `accelerometerTrims` 是否设置正确
3. 加速度计数据是否在合理范围内（0.9G - 1.1G）

### Q3: 角度环响应过慢或过快
**调整参数：**
1. `pidProfile->pid[PID_LEVEL].P` - 角度环增益
2. `pidProfile->angle_feedforward_smoothing_ms` - 前馈平滑时间
3. `ATTITUDE_CUTOFF_HZ` - 姿态滤波器截止频率（默认50Hz）

## 总结

角度环移植的核心步骤：

1. ✅ **启用加速度计** - 确保 `USE_ACC` 定义，实现加速度计初始化和数据读取
2. ✅ **实现姿态估计** - 使用Mahony AHRS算法融合陀螺仪和加速度计数据
3. ✅ **实现角度环** - 在 `pidLevel` 函数中将角度误差转换为角速度设定点
4. ✅ **集成到PID控制器** - 在 `pidController` 中根据飞行模式调用角度环
5. ✅ **初始化参数和滤波器** - 在 `pidInitFilters` 和 `pidInitConfig` 中初始化相关参数
6. ✅ **测试验证** - 使用调试通道验证各个部分是否正常工作

完成这些步骤后，角度环应该能够正常工作，飞行器可以在ANGLE_MODE和HORIZON_MODE下实现自稳功能。
