# ICM-42688-P坐标系数据详解

## 一、ICM-42688-P芯片坐标系定义

根据芯片数据手册和示意图，ICM-42688-P的坐标系定义如下：

### 1.1 轴方向定义

- **+X轴**：水平方向，从芯片前右侧面延伸（实线）
  - **重要**：在飞行器应用中，**X轴正方向通常指向机头方向**
  - 即：**机头方向 = +X轴方向**
- **+Y轴**：水平方向，从芯片前左侧面延伸（虚线）
  - 在飞行器应用中，**Y轴正方向通常指向右侧**
- **+Z轴**：垂直方向，从芯片顶部中心向上延伸（虚线）
  - 在飞行器应用中，**Z轴正方向通常指向天空（向上）**

### 1.2 旋转方向（右手定则）

旋转方向遵循**右手定则**：
- 右手拇指指向**旋转轴的正方向**
- 四指弯曲方向为**正旋转方向**
- 与四指弯曲方向相反为**负旋转方向**

**具体定义**：

- **绕X轴旋转（Roll）**：
  - 右手拇指指向**+X方向**（机头方向）
  - 四指弯曲方向：从+Y转向-Z（右侧向下旋转）
  - **正旋转** = **右滚**（右侧向下）
  - **负旋转** = **左滚**（左侧向下）

- **绕Y轴旋转（Pitch）**：
  - 右手拇指指向**+Y方向**（右侧方向）
  - 四指弯曲方向：从+X转向+Z（机头向上旋转）
  - **正旋转** = **抬头**（机头向上）
  - **负旋转** = **低头**（机头向下）

- **绕Z轴旋转（Yaw）**：
  - 右手拇指指向**+Z方向**（向上）
  - 四指弯曲方向：从+X转向+Y（顺时针旋转，从上方看）
  - **正旋转** = **顺时针旋转**（从上方看）
  - **负旋转** = **逆时针旋转**（从上方看）

## 二、静止状态下的原始数据

### 2.1 加速度计（Accelerometer）原始数据

当芯片**水平放置**（芯片顶部朝上，Z轴向上）且**完全静止**时：

#### 情况A：芯片水平放置，Z轴向上

```
芯片状态：
  - 芯片顶部朝上
  - Z轴指向天空
  - X轴和Y轴在水平面内
```

**加速度计原始读数**：
- **X轴（ADCRaw[X]）**：≈ **0**
  - 原因：水平方向无重力分量
- **Y轴（ADCRaw[Y]）**：≈ **0**
  - 原因：水平方向无重力分量
- **Z轴（ADCRaw[Z]）**：≈ **-1G**（负值）
  - 原因：重力向下（-Z方向），而Z轴定义向上，所以为负值
  - 数值：约 -256（假设1G = 256 LSB）

**代码位置**：
```491:493:src/main/drivers/accgyro/accgyro_spi_icm456xx.c
           acc->ADCRaw[X] = (int16_t)((raw[1] << 8) | raw[0]);
           acc->ADCRaw[Y] = (int16_t)((raw[3] << 8) | raw[2]);
           acc->ADCRaw[Z] = (int16_t)((raw[5] << 8) | raw[4]);
```

#### 情况B：芯片翻转，Z轴向下

```
芯片状态：
  - 芯片底部朝上
  - Z轴指向地面
```

**加速度计原始读数**：
- **X轴（ADCRaw[X]）**：≈ **0**
- **Y轴（ADCRaw[Y]）**：≈ **0**
- **Z轴（ADCRaw[Z]）**：≈ **+1G**（正值）
  - 原因：重力向下，Z轴也向下，方向一致，所以为正值

### 2.2 陀螺仪（Gyroscope）原始数据

当芯片**完全静止**（无旋转）时：

**陀螺仪原始读数**：
- **X轴（gyroADCRaw[X]）**：≈ **零偏值**（可能不为0）
  - 静止时应该为0，但存在零偏（gyroZero）
  - 校准时会计算并减去零偏
- **Y轴（gyroADCRaw[Y]）**：≈ **零偏值**
- **Z轴（gyroADCRaw[Z]）**：≈ **零偏值**

**代码位置**：
```589:591:src/main/drivers/accgyro/accgyro_spi_icm456xx.c
        gyro->gyroADCRaw[X] = (int16_t)((gyro->dev.rxBuf[2] << 8) | gyro->dev.rxBuf[1]);
        gyro->gyroADCRaw[Y] = (int16_t)((gyro->dev.rxBuf[4] << 8) | gyro->dev.rxBuf[3]);
        gyro->gyroADCRaw[Z] = (int16_t)((gyro->dev.rxBuf[6] << 8) | gyro->dev.rxBuf[5]);
```

**零偏校准**：
```236:239:src/main/sensors/gyro.c
                // please take care with exotic boardalignment !!
                gyroSensor->gyroDev.gyroZero[axis] = gyroSensor->calibration.sum[axis] / gyroCalculateCalibratingCycles();
                if (axis == Z) {
                  gyroSensor->gyroDev.gyroZero[axis] -= ((float)gyroConfig()->gyro_offset_yaw / 100);
                }
```

## 三、不同方向运动时的数据变化

### 3.1 加速度计数据变化

#### 情况1：向+X方向加速（沿X轴正方向运动）

**运动描述**：芯片沿+X轴方向加速运动

**加速度计读数变化**：
- **X轴（ADCRaw[X]）**：**正值增加**
  - 例如：从0变为+100（假设加速度为0.4G）
- **Y轴（ADCRaw[Y]）**：**不变**（仍为0）
- **Z轴（ADCRaw[Z]）**：**不变**（仍为-1G，重力不变）

**数据示例**：
```
静止时：  X=0,    Y=0,    Z=-256
加速时：  X=+100, Y=0,    Z=-256
```

#### 情况2：向-X方向加速（沿X轴负方向运动）

**加速度计读数变化**：
- **X轴（ADCRaw[X]）**：**负值增加**
  - 例如：从0变为-100
- **Y轴（ADCRaw[Y]）**：**不变**
- **Z轴（ADCRaw[Z]）**：**不变**

#### 情况3：向+Y方向加速（沿Y轴正方向运动）

**加速度计读数变化**：
- **X轴（ADCRaw[X]）**：**不变**
- **Y轴（ADCRaw[Y]）**：**正值增加**
  - 例如：从0变为+100
- **Z轴（ADCRaw[Z]）**：**不变**

#### 情况4：向+Z方向加速（向上加速）

**加速度计读数变化**：
- **X轴（ADCRaw[X]）**：**不变**
- **Y轴（ADCRaw[Y]）**：**不变**
- **Z轴（ADCRaw[Z]）**：**负值减小**（绝对值减小）
  - 例如：从-256变为-156（向上加速抵消部分重力）
  - 如果向上加速度为1G，Z轴读数变为0
  - 如果向上加速度为2G，Z轴读数变为+256

**数据示例**：
```
静止时：      X=0,    Y=0,    Z=-256
向上1G加速：  X=0,    Y=0,    Z=0
向上2G加速：  X=0,    Y=0,    Z=+256
```

#### 情况5：向-Z方向加速（向下加速）

**加速度计读数变化**：
- **X轴（ADCRaw[X]）**：**不变**
- **Y轴（ADCRaw[Y]）**：**不变**
- **Z轴（ADCRaw[Z]）**：**负值增加**（绝对值增大）
  - 例如：从-256变为-356（向下加速叠加重力）

#### 情况6：芯片倾斜（Roll倾斜）

**运动描述**：
- **机头方向**：与**X轴正方向**一致（X轴指向机头）
- **旋转轴**：绕X轴旋转（Roll轴）
- **旋转方向**：按照**右手定则**
  - 右手拇指指向+X方向（机头方向）
  - 四指弯曲方向为**正旋转方向**（右滚为正）
  - 例如：右侧向下倾斜 = 正旋转（右滚）

**具体示例**：
- **右滚（右侧向下）**：
  - 右手拇指指向+X（机头方向）
  - 四指弯曲方向：从+Y转向-Z（右侧向下）
  - 这是**正旋转**，陀螺仪X轴读数为**正值**
- **左滚（左侧向下）**：
  - 右手拇指指向+X（机头方向）
  - 四指弯曲方向：从-Y转向-Z（左侧向下）
  - 这是**负旋转**，陀螺仪X轴读数为**负值**

**加速度计读数变化**（右滚30度）：
- **X轴（ADCRaw[X]）**：**不变**（仍为0）
  - 原因：绕X轴旋转，X轴方向不变，重力在X轴无分量
- **Y轴（ADCRaw[Y]）**：**正值增加**
  - 原因：重力在+Y方向产生分量（右侧向下，重力分量指向+Y）
  - 倾斜角度越大，Y轴读数越大
  - 例如：右滚30度，Y轴≈+128（0.5G = sin(30°) × 1G）
- **Z轴（ADCRaw[Z]）**：**负值减小**（绝对值减小）
  - 原因：重力在Z轴的分量减小（部分重力转移到Y轴）
  - 例如：右滚30度，Z轴≈-222（0.866G = cos(30°) × 1G）

**数据示例**（右滚30度）：
```
水平时：    X=0,    Y=0,    Z=-256
右滚30度：  X=0,    Y=+128, Z=-222
左滚30度：  X=0,    Y=-128, Z=-222
```

**陀螺仪读数变化**（Roll旋转时）：
- **X轴（gyroADCRaw[X]）**：
  - **右滚**：**正值**（例如：+500度/秒）
  - **左滚**：**负值**（例如：-500度/秒）
- **Y轴（gyroADCRaw[Y]）**：**≈ 0**（无Y轴旋转）
- **Z轴（gyroADCRaw[Z]）**：**≈ 0**（无Z轴旋转）

#### 情况7：芯片倾斜（Pitch倾斜）

**运动描述**：
- **机头方向**：与**X轴正方向**一致（X轴指向机头）
- **旋转轴**：绕Y轴旋转（Pitch轴）
- **旋转方向**：按照**右手定则**
  - 右手拇指指向+Y方向（右侧方向）
  - 四指弯曲方向为**正旋转方向**（抬头为正）
  - **抬头倾斜**：机头向上倾斜 = 正旋转（四指从+X转向+Z）
  - **低头倾斜**：机头向下倾斜 = 负旋转（四指从-X转向-Z）

**加速度计读数变化**（低头30度）：
- **X轴（ADCRaw[X]）**：**正值增加**
  - 原因：重力在+X方向产生分量（机头向下，重力分量指向+X）
  - 例如：低头30度，X轴≈+128（0.5G = sin(30°) × 1G）
- **Y轴（ADCRaw[Y]）**：**不变**（仍为0）
  - 原因：绕Y轴旋转，Y轴方向不变，重力在Y轴无分量
- **Z轴（ADCRaw[Z]）**：**负值减小**（绝对值减小）
  - 原因：重力在Z轴的分量减小（部分重力转移到X轴）
  - 例如：低头30度，Z轴≈-222（0.866G = cos(30°) × 1G）

**数据示例**（低头30度）：
```
水平时：    X=0,    Y=0,    Z=-256
低头30度：  X=+128, Y=0,    Z=-222
抬头30度：  X=-128, Y=0,    Z=-222
```

**陀螺仪读数变化**（Pitch旋转时）：
- **X轴（gyroADCRaw[X]）**：**≈ 0**（无X轴旋转）
- **Y轴（gyroADCRaw[Y]）**：
  - **抬头**：**正值**（例如：+500度/秒）
  - **低头**：**负值**（例如：-500度/秒）
- **Z轴（gyroADCRaw[Z]）**：**≈ 0**（无Z轴旋转）

## 五、实际测试验证方法

### 5.1 验证加速度计

1. **水平静止测试**：
   - 将芯片水平放置（Z轴向上）
   - 读取原始数据：X≈0, Y≈0, Z≈-256（或接近-1G的值）

2. **翻转测试**：
   - 将芯片翻转（Z轴向下）
   - 读取原始数据：X≈0, Y≈0, Z≈+256

3. **倾斜测试**：
   - 将芯片倾斜30度（绕X轴）
   - 读取原始数据：Y轴应该有明显的正值

### 5.2 验证陀螺仪

1. **静止测试**：
   - 芯片完全静止
   - 读取原始数据：各轴应该接近零偏值（可能不为0）

2. **旋转测试**：
   - 缓慢旋转芯片绕X轴
   - 读取原始数据：X轴应该有明显的正值或负值

## 六、注意事项

### 6.1 坐标系转换

**重要**：ICM-42688-P的原始坐标系可能与Betaflight标准坐标系不一致，需要通过`gyro_align`和`acc_align`参数进行转换。

### 6.2 重力方向

- 如果Z轴定义向上，静止时Z轴加速度为**负值**（-1G）
- 如果Z轴定义向下，静止时Z轴加速度为**正值**（+1G）

### 6.3 数据单位

- **加速度计**：LSB（Least Significant Bit），需要转换为G值
  - 通常1G = 256 LSB（取决于量程设置）
- **陀螺仪**：LSB，需要转换为度/秒
  - 通常需要乘以scale因子

### 6.4 零偏处理

- **陀螺仪**：静止时不为0，需要校准零偏
- **加速度计**：静止时Z轴不为0（有重力），需要校准

## 总结

ICM-42688-P芯片的原始数据遵循其定义的坐标系：
- **加速度计**：静止时Z轴为-1G（Z轴向上）或+1G（Z轴向下）

这些原始数据经过传感器对齐、板对齐和零偏校准后，才能用于姿态估计和控制。
